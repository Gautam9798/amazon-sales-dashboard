# Amazon Sales Dashboard

## 📊 Project Overview

An interactive sales analytics dashboard built using **Power BI and Excel** to analyze Amazon sales performance and identify key trends across order status, product categories, delivery partners, payment methods, and sales.

The project demonstrates an end-to-end data analysis workflow including data preparation, visualization, KPI analysis, and business insights.

## 🎯 Business Objectives

The dashboard was developed to answer key business questions:

- What is the total sales generated?
- What is the distribution of order statuses?
- Which product categories have the highest number of orders?
- Which delivery partners handle the most orders?
- Which payment methods are most frequently used?
- How do sales performance and order activity vary across the dataset?

## 🛠️ Tools & Technologies

- **Power BI** – Interactive dashboard and data visualization
- **Excel** – Data preparation and analysis
- **Data Analysis** – KPI development and business insights

## 📈 Dashboard Features

The dashboard includes:

- Total Sales KPI
- Order Status Distribution
- Top Product Categories
- Delivery Partner Analysis
- Payment Method Analysis
- Interactive Order Date filtering
- Visual comparison of key sales metrics

## 🔍 Key Analysis

The dashboard provides a consolidated view of sales performance and customer order behavior.

Key areas analyzed include:

1. **Sales Performance** – Overall sales generated across the dataset.
2. **Order Status** – Distribution of delivered, shipped, cancelled, and other orders.
3. **Product Categories** – Identification of the most frequently ordered categories.
4. **Delivery Partners** – Comparison of order fulfillment across delivery partners.
5. **Payment Methods** – Analysis of customer payment preferences.
